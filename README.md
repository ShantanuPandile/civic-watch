# Smart Civic Issue Reporting & Tracking Platform

Smart Civic Issue Reporting & Tracking Platform is a web-based solution designed to make civic problem reporting simple, organised, and transparent.

Citizens can report common issues such as potholes, broken streetlights, garbage problems, and other infrastructure complaints through an easy-to-use online form. The submitted reports are stored in a central SQLite database and displayed in an organised list, making complaints easier to view and manage.

The platform provides a clean, responsive interface that can be used on both desktop and mobile devices. Location support using Leaflet and OpenStreetMap helps connect reported issues with their actual location.

### Key Features

* Citizen-friendly issue reporting form
* Issue description and category
* Centralised complaint storage
* Reports list for viewing submitted issues
* Location support with interactive maps
* Simple and mobile-friendly design

### Technology

Python Flask, SQLite, HTML, CSS, JavaScript, Leaflet, and OpenStreetMap.

The platform can be further expanded with GPS-based reporting, photo uploads, AI classification, severity and priority scoring, duplicate complaint detection, live status tracking, an authority dashboard, and Civic Credits.

The goal is to provide a practical digital system that helps citizens report civic problems efficiently and makes issue management more organised.
